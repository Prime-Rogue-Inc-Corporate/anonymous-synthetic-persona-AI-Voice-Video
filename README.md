# anonymous-synthetic-persona-AI-Voice-Video

A synthetic persona for audio-video generation: give it text, get back an old-school "We are Anonymous" broadcast with a flat robot voice, glitchy captions and a moth-in-a-suit emblem.

Current version: see [`VERSION`](VERSION) · history in [`CHANGELOG.md`](CHANGELOG.md).

## Requirements

- `ffmpeg` and `espeak-ng` on your PATH (`apt install ffmpeg espeak-ng`)
- Python 3.10+ and `pip install -r requirements.txt`
- DejaVu fonts (`/usr/share/fonts/truetype/dejavu`, standard on most Linux)

## Making an episode

1. Create `episodes/NNN-slug/script.txt`, one caption line per line. Follow the format:
   `Greetings, <target>.` → `We are Anonymous.` → the text → the five sign-off lines
   (`We are Anonymous.` / `We are Legion.` / `We do not forgive.` / `We do not forget.` / `Expect us.`).
2. Add `episode.json` (every key is optional; see `DEFAULTS` in `persona/render.py`):

```json
{
  "subtitle": "message to podiatry",
  "mask": "moth",
  "credits": ["for Norm"],
  "voice": {"speed": 138},
  "pronounce": {"Qatar": "Kuh-tar"},
  "gaps": {"after": {"\"'Cause": 2.2}},
  "light": {"line": "\"'Cause", "color": [255, 210, 120], "ramp": 0.15, "tint": [0.45, 0.38, 0.18]},
  "output": "greetings_podiatrist.mp4"
}
```

   - `light.line`: the caption line where the light comes up (prefix match).
   - `gaps.after`: extra pause (seconds) after lines starting with the given prefix — use it for comic beats.
   - `pronounce`: respellings sent to the voice only; captions keep the original text.
3. Check a few frames, then render:

```bash
python persona/render.py episodes/NNN-slug --preview   # PNGs in episodes/NNN-slug/build/
python persona/render.py episodes/NNN-slug --jobs 4    # full render
```

Rendering runs at roughly 2× real time per core, so an 18-minute speech takes about 30 minutes on two cores.

## Dialogue

Tag each line with a speaker and define the cast:

```
ANCHOR: Doctor Wren. Seven records. How should people feel?
WREN: Proud. Very few planets set seven records in a single year.
```

```json
"cast": {
  "ANCHOR": {"name": "Dana Kerr, anchor", "mask": "anchor", "x": 0.3, "color": [150, 190, 255],
             "voice": {"voice": "en-us+f3", "speed": 150, "pitch": 40}},
  "WREN":   {"name": "Dr. Ellis Wren", "mask": "expert", "x": 0.7, "color": [255, 205, 120],
             "voice": {"voice": "en-us+m7", "speed": 162, "pitch": 58}}
}
```

Each speaker gets their own espeak-ng voice (anything from `espeak-ng --voices`, plus a `+variant`), their own mask and their own voice-driven animation. Whoever isn't talking is dimmed. Leave `cast` out for a solo persona.

### Ensembles, narrators and sets

Any number of speakers works; the layout scales for 3 and 4+. A cast member with `"mask": null` is voice-only, which is handy for a narrator. Dress the room with `"set"`:

```json
"cast": {
  "NARRATOR": {"name": "Anonymous", "mask": null},
  "WADE":  {"mask": "rancher",  "x": 0.14, "card": "ALBERTA", "voice": {"voice": "en-us+m1", "pitch": 28}},
  "BRENT": {"mask": "official", "x": 0.62, "card": "STATE",   "voice": {"voice": "en-us+m3", "pitch": 48}}
},
"set": {"table": true, "placard": "SCIF · NO PERSONAL ELECTRONIC DEVICES BEYOND THIS POINT", "lockbox": true},
"signoff_lines": 6
```

`signoff_lines` is how many closing lines count as the sign-off (default 5); raise it if the sign-off has an extra button.

### Walk-and-talk

A moving corridor, two leads walking toward camera, and walk-ons who cut in from the side:

```json
"cast": {
  "GWEN":  {"mask": "chief",   "x": 0.37, "walk": true, "cadence": 1.9},
  "THEO":  {"mask": "counsel", "x": 0.63, "walk": true, "cadence": 2.0},
  "RUDY":  {"mask": "clerk",   "x": 0.11, "walk": true, "enter": "left",  "scale": 0.86, "top": 175},
  "PRIYA": {"mask": "aide",    "x": 0.89, "walk": true, "enter": "right", "scale": 0.86, "top": 175}
},
"layout": {"scale": 1.02, "top": 128},
"set": {"corridor": {"speed": 1.5, "plaques": ["S-219", "CLOAKROOM", "PARLIAMENTARIAN"]}},
"gaps": {"default": 0.22}
```

Walk-ons appear for each burst of their lines and leave afterwards. A short `gaps.default` and faster voice `speed` give it the pace.

### Floor speeches

```json
"cast": {
  "WHITLOW": {"mask": "congressman", "x": 0.33, "scale": 1.0, "top": 112},
  "CHAIR":   {"mask": "presiding", "x": 0.74, "scale": 0.42, "top": 150, "gavel": true, "desk": true, "desk_y": 290},
  "TEAGUE":  {"mask": "whip", "x": 0.88, "scale": 0.9, "top": 200, "enter": "right"}
},
"set": {
  "chamber": {"flag_x": 0.74},
  "lectern": {"x": 0.33, "y": 492, "seal": true},
  "chyron": {"title": "U.S. HOUSE OF REPRESENTATIVES", "sub": "SPECIAL ORDER",
             "clock": {"from": 3600, "start": "Greetings", "zero": "The gentleman's time has expired"}}
}
```

Put `[gavel]` in a line (`CHAIR: [gavel] The gentleman will suspend.`) for a knock. Note that `gaps.after` prefixes match the raw line, so include the cue if you key a gap off a gavelled line.

  "WHITLOW": {"mask": "congressman", "x": 0.8, "top": 150, "screen": true, "screen_label": "REP. WHITLOW · OHIO"},
  "DALE":    {"mask": null}
},
"set": {
  "barn": {"moose_x": 0.8, "frame_x": 0.6, "headshot_caption": "PRIME TIME"},
  "desk": {"x": 0.36, "y": 506, "w": 640, "mic": true, "mic_x": 640, "mic_y": 420, "mug": true},

### House of Commons

```json
"set": {"commons": {"chair_x": 0.56, "table_y": 492, "boxes": [0.3, 0.78]}}
```

Oak panelling, the Speaker's chair at the far end, green benches converging on it, the red lines on the carpet, and the Table in front with the mace and a despatch box at each `boxes` position. `[hear]` is a bench of members growling "hear, hear".

### Rallies and briefing rooms

```json
"set": {"rally": {"banner": ["STRONGER", "TOGETHER"]}}
```

An arena with a lighting truss, a red-and-white banner and flags, and a foreground crowd with flags, hockey sticks and signs that jumps and waves after each `[cheer]`.

```json
"set": {"table": true,
        "slides": {"x": 0.56, "w": 420, "h": 196, "first": "TITLE\nsubtitle",
                   "cues": [["phrase from the script", "SLIDE TITLE\nline two"], ["Pull up a map.", "MAP"]]}}
```

A projector screen whose slide changes when each phrase is spoken. `"MAP"` draws a crude map of Canada. `[slam]` is a door flung open.

### The North and the road

`"set": {"arctic": {"breath": true}}` is an Arctic night with moving aurora, distant hamlet lights, a research station, a snowmobile and a sled; with `breath`, whoever is speaking puffs visible breath. `"set": {"diner": {}}` is a highway truck stop at night: panelling, a window onto idling semis, a neon EAT sign, a counter and a pie case. Pair it with `"desk"` for the booth table. On the arctic set, `"twilight": true` swaps night for a November noon (no stars), `"aurora": false` turns the lights off, and `"range": {"plates": [...]}` adds steel plates that swing on each `[ding]`; `[shot]` adds a muzzle flash at the shooter. `[laugh]` is a few people cracking up.

`"set": {"prairie": {"on": true}}` is a rifle range on the prairie in November, seen from under the firing-line shelter; `[jet]` sends a fighter across the sky with a roar. `"set": {"boardroom": {"on": true}}` is an Ottawa boardroom at dusk with a snowy view of the Hill. `"set": {"hall": {"board": ["line", ...]}}` is a northern community hall: block walls, a bingo board, a whiteboard roster, a dark window and a roof stain. End any line with `{= translation}` to speak the line as written and show the translation as a smaller gold subtitle under the caption: `NATHAN: Chu là. {= I'm in.}`. French voices are `fr-fr`, `fr-be` and `fr-ch` with the usual `+m1`…`+f5` variants. A cast entry with `"duet": ["A", "B"]` (and `"mask": null`) speaks its lines in both voices at once and moves both mouths: `BOTH: Oh.`

### Verbatim episodes

For real speeches by real people, the rule is: the words are theirs, exactly, and nothing else is.

- Use a public-domain source (US federal works by officials in their official capacity, 17 U.S.C. 105) and cite it in `credits`.
- Pick one contiguous stretch. Lines are only split at sentence or comma boundaries; joined back together they must equal the source excerpt (010 checks this against `SOURCE.md`).
- Speak through the channel persona (`moth`) or an invented, non-likeness mask (010 uses `orator`); never draw a likeness or caricature of a living person. Make it thematic through the set instead: props can fire on phrases from the speech.
- Put framing in a voice-only `NARRATOR`, never in the speaker's mouth. `"signoff_lines": 0` drops the "We are Anonymous" sign-off, and `"end_title"` replaces "EXPECT US." on the end card.
- Number and symbol fixes for the synth go in `pronounce`, which changes the audio only, never the captions.

```json
"set": {
  "assembly": {"x": 0.5, "width": 0.42,
               "escalator": true, "escalator_stops": "stopped right in the middle",
               "teleprompters": true, "teleprompter_on": "It just went on",
               "terrazzo_at": "You walk on terrazzo"},
  "lectern":  {"x": 0.5, "y": 500, "color": [46, 84, 66], "marble": true}
},
"signoff_lines": 0,
"end_title": "AS DELIVERED."
```

## Loop clips

Pull a seamless loop out of any rendered episode by naming its first and last caption lines:

```bash
python tools/loop_clip.py episodes/002-lyceum-address --from "If destruction" --to "As a nation of freemen" --name destruction --repeat 4
```

Writes `episodes/<ep>/clips/<name>_loop.mp4` (one cycle, crossfaded tail-into-head) and `<name>_x4.mp4`.
